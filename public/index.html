⚡ Atajo para añadir gastos sin abrir la app

Crea un botón en tu iPhone o Android que registra un gasto al instante — desde la pantalla de inicio, Siri, o un widget. No necesitas abrir MoneyPro. Los gastos del atajo se ven en tus movimientos la próxima vez que abras sesión (se sincronizan solos).

Generando…

Usa siempre el botón «Copiar token» (no lo escribas a mano ni lo copies de otro lado) — un solo carácter distinto y el atajo deja de funcionar sin avisar por qué.

El atajo solo funciona con una cuenta real (no en modo demostración).

  1. Abre la app Atajos de Apple → pestaña Atajos → toca +. Empieza por un campo con tu token — así, si algún día compartes el atajo, quien lo reciba solo edita este único valor.
  2. Agrega «Texto»: pega tu token (botón «📋 Copiar token»).
  3. Opcional pero recomendado — pregunta Gasto/Ingreso: agrega «Lista» con dos elementos (Gasto, Ingreso), luego «Seleccionar de la lista» (mensaje «¿Gasto o ingreso?»), y dos «Reemplazar texto» encadenadas: Gasto→expense (en el elemento elegido), luego Ingreso→income (en el resultado de la anterior). El resultado final es tu variable "Tipo". Si te lo saltas, usa expense fijo más abajo.
  4. Agrega «Texto»: arma la URL de categorías combinando texto y variables, todo en una línea: la base fija de la URL (botón «1. Copiar URL de categorías», pero corta el token y el tipo del final) + tu variable de Texto (token) + / + tu variable "Tipo" (o expense) + .json.
  5. Agrega «Obtener contenido de URL» con la URL del paso anterior (GET, sin tocar método ni cuerpo).
  6. Agrega «Elegir de la lista»: en el campo Lista, usa la variable «Contenido de URL» del paso anterior.
  7. Agrega «Preguntar por texto» (para el monto).
  8. Agrega otro «Texto»: la base de la URL de guardar + tu variable de Texto (token) + .json (compárala con el botón «2. Copiar URL para guardar» para la base correcta).
  9. Agrega «Obtener contenido de URL» con esa URL, Método POST, «Cuerpo de la solicitud» → JSON. Agrega tres campos: amount (tipo Número, variable del monto), type (tu variable "Tipo", o expense fijo), category (variable «Elemento elegido» de «Elegir de la lista»). No agregues un campo token — ya no hace falta, va en la URL.
  10. Renombra el atajo y agrégalo a tu pantalla de inicio: ⋯ → «Añadir a inicio». Para compartirlo: ⋯ → Compartir → Copiar enlace de iCloud — quien lo reciba solo edita el «Texto» del paso 2 con su propio token.
  1. Instala HTTP Shortcuts (gratis, de Waboodoo) desde Play Store o F-Droid.
  2. Ve a Variables → crea una variable tipo Selección — algunas versiones permiten cargar las opciones "desde una petición HTTP"; si la tuya lo permite, apunta esa petición a la URL del botón «1. Copiar URL de categorías» (GET) para que el menú se llene solo con tus categorías.
  3. Si tu versión no lo permite: crea la variable Selección con las opciones escritas a mano (deben coincidir con tus categorías actuales — revísalas en la sección "Categorías" de arriba, ya que puedes editarlas).
  4. Crea el atajo: método POST, pega tu URL (botón «2. Copiar URL para guardar»), «Cuerpo de la solicitud» → JSON personalizado, pega la plantilla (botón «3. Copiar cuerpo JSON»). Reemplaza el 0 de "amount" por una variable Número, y el texto comida de "category" por tu variable Selección.
  5. Coloca el atajo como widget en tu pantalla de inicio. Un toque y el gasto queda registrado.
